# Image prompts — clara-hale

Generated by `_build/prompts.js` from the provenance in `cases/clara-hale/case.js`.
Paste each prompt into the image model, save the result as the filename shown,
then run `python3 _build/plates.py` to render its provenance and finish it.

The shared style block is already inlined into every prompt. The negatives matter:
without them a model defaults to an airbrushed studio headshot, which is exactly the
look the plates then have to fight.
